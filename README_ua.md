# MooS Calculator v0.11.8 (Stalzone)
**Language:** [Русский](README_ru.md) | [English](README.md) | Українська
**Автор:** 2TheMoon / TheMoom  
**Замовник (Requested by):** Serega_Aspect  

Інструмент для швидкого підрахунку вартості ігрових предметів за скріншотами для гри **Stalzone**. Скопіюйте скріншот у буфер обміну, натисніть `Ctrl+V` — програма автоматично розпізнає предмети, зчитає їхню кількість та розрахує загальну суму. Також містить вбудований калькулятор із підтримкою OCR.

> **Важливо:**
> * Режим **«Пошта»** відкалібрований для інтерфейсу пошти/сховища Stalzone.
> * Для роботи вкладок **«Торгівля»** та розпізнавання чисел зі скріншота потрібна **Windows 10/11** із вбудованим мовним пакетом розпізнавання тексту (Windows OCR).

---

## Режими роботи (Вкладки)

1. **Пошта** — візуальний аналіз сітки інвентарю: пошук слотів, порівняння іконок за формою та кольором (`items/`), зчитування кількості за шаблонами цифр (`digits/`).
2. **Торгівля** — текстовий аналіз списків формату `Назва x 126` через Windows OCR із нечітким пошуком та автоматичним виправленням типових помилок розпізнавання.
3. **Калькулятор** — вбудований калькулятор (`+`, `−`, `×`, `÷`, `%`, `±`) із підтримкою пріоритету операцій, перенесенням суми з таблиці та вставкою чисел безпосередньо зі скріншотів.

## Структура файлів і папок

Поруч із виконуваним файлом (`MooSC v0.11.8.exe` або `calculator.py`) розташовуються робочі директорії та конфігурації:

| Файл / Папка | Призначення |
| :--- | :--- |
| `MooSC v0.11.8.exe` | Виконуваний файл програми. |
| `prices.txt` | База цін у форматі `Назва=ціна`. |
| `items/` | Еталонні зображення слотів предметів (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`). |
| `digits/` | Шаблони цифр (`0.png`–`9.png`) та автоматично створені приклади (`3_ex1.png` тощо). |
| `Errors/` | *Створюється автоматично.* Сюди зберігаються унікальні нерозпізнані слоти. |

## Швидкий старт та налаштування

### 1. Налаштування цін
У базовому комплекті файл `prices.txt` може бути порожнім:
1. Запустіть програму та натисніть **«Обновить prices.txt»** — усі предмети з папки `items/` додадуться до файлу зі стартовою ціною `1`.
2. Вкажіть актуальні ціни подвійним кліком по клітинці **«Цена»** в таблиці або відредагуйте `prices.txt` у будь-якому текстовому редакторі.

### 2. Встановлення Windows OCR (для «Торгівлі» та вставки чисел)
Якщо програма повідомляє про помилку запуску розпізнавання тексту, встановіть мовний пакет через **PowerShell (від імені адміністратора)**:

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
```
*(Програма підтримує мови `ru` та `uk`, за замовчуванням використовується перша доступна зі списку).*

## Детальний посібник за вкладками

### Вкладка «Пошта» (Розпізнавання іконок)
1. Зробіть скріншот області зі слотами предметів (наприклад, `Win + Shift + S`).
2. Натисніть **«Вставить скриншот»** або `Ctrl+V`.
3. Програма виведе таблицю з позицією `(ряд, колонка)`, мініатюрою, назвою, кількістю, ціною, сумою, візуальною часткою від підсумку та коефіцієнтом збігу.

**Кольорова індикація рядків:**
* **Зелений** — найдорожча позиція у списку.
* **Жовтий** — предмет розпізнано, але для нього не задано ціну в `prices.txt`.
* **Червоний** — предмет не розпізнано (із зазначенням найближчого кандидата, якщо його знайдено).

**Редагування та самонавчання (подвійний клік по клітинці):**
* **Предмет:** Дозволяє задати назву нерозпізнаному предмету (іконка автоматично збережеться в `items/`) або перейменувати вже відомий (файл у `items/` та запис у `prices.txt` оновляться автоматично).
* **Кол-во (Кількість):** Виправляє неправильно зчитане число. Якщо кількість знайдених на слоті гліфів збігається з довжиною введеного числа, програма збереже нові зразки цифр у `digits/` (наприклад, `5_ex1.png`) та одразу перерахує решту слотів.
* **Цена (Ціна):** Змінює вартість предмета та миттєво зберігає її в `prices.txt` (залиште поле порожнім, щоб видалити ціну).

> **Примітка:** У назвах заборонені символи `\ / : * ? " < > | =`, а також символи `#` і `?` на початку рядка. Для разового підтвердження кандидата без збереження в `items/` натисніть **«✔ принять»** у колонці «Подтв.».

### Вкладка «Торгівля» (Розпізнавання тексту)
Призначена для скріншотів текстових списків вигляду `Мякоть солевика x 126`.
1. Перейдіть на вкладку **«Торговля»** та вставте скріншот (`Ctrl+V`).
2. Програма обробить зображення через кілька фільтрів (збільшення, видалення віньєтки, підвищення різкості, бінаризація) та зіставить рядки з базою `prices.txt`, `trade_examples.txt` і `trade_aliases.txt`.
3. Якщо OCR спотворив назву, виправте її подвійним кліком по клітинці **«Предмет»** або прийміть запропонованого кандидата — програма запише правило до `trade_aliases.txt` і надалі виправлятиме цю помилку автоматично.

---

### Вкладка «Калькулятор»
Повноцінний калькулятор із підтримкою введення з клавіатури (`0-9`, `+`, `-`, `*`, `/`, `%`, `Enter`/`=`, `Backspace`, `Esc`/`Delete` для скидання, `Ctrl+C` для копіювання).

**Спеціальні функції:**
* **← ИТОГО из таблицы:** Переносить загальну суму з останнього розрахунку в «Пошті» або «Торгівлі».
* **Вставить число (`Ctrl+V`):** Розпізнає число з тексту в буфері обміну або безпосередньо зі скріншота (наприклад, `8 650 000 рублей` перетвориться на `8650000`). Вставлене число підставляється як поточний операнд, не стираючи вже набраний вираз (наприклад, `100 + [вставка]`).

## Панель керування та підготовка бази

* **↻ Перезагрузить:** Перечитує папки `items/`, `digits/` та файл `prices.txt`, заново аналізуючи поточний скріншот.
* **Сохранить слоты/цифры:** Вивантажує до папки `debug/` нарізані слоти (`debug/slots/`) та символи (`debug/glyphs/`), а в режимі торгівлі — варіанти передобробки для OCR. Зручно використовувати для наповнення папок `items/` та `digits/` чистими еталонами.
* **Папка Errors:** Відкриває директорію з автоматично збереженими нерозпізнаними предметами (дублікати відсіюються автоматично).
* **Обновить prices.txt:** Синхронізує `prices.txt` із вмістом папки `items/`, додаючи нові предмети з ціною `1` та зберігаючи наявні ціни й коментарі.

## Вирішення частих проблем

* **«В буфере обмена нет скриншота»** — переконайтеся, що скопійовано саме зображення, а не файл у провіднику чи текст.
* **Усі предмети не розпізнано** — перевірте, що в папці `items/` є еталони і вони зняті в тому самому масштабі інтерфейсу гри, що й новий скріншот.
* **Кількість завжди визначається як `1`** — перевірте індикатор у верхній частині вікна: має бути `цифр: 10/10`. Переконайтеся, що в папці `digits/` лежать файли `0.png`–`9.png`.
* **Неточне розпізнавання числа зі скріншота в калькуляторі** — намагайтеся обрізати скріншот максимально щільно навколо потрібного числа, щоб у кадр не потрапляв зайвий ігровий інтерфейс.
