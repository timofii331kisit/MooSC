# MooS Calculator v0.11.8 (Stalzone)
**Language:** Русский | [English](README.md) | [Українська](README_ua.md)
**Автор:** 2TheMoon / TheMoom  
**Заказчик (Requested by):** Serega_Aspect  

Инструмент для быстрого подсчёта стоимости игровых предметов по скриншотам для игры **Stalzone**. Скопируйте скриншот в буфер обмена, нажмите `Ctrl+V` — программа автоматически определит предметы, распознает их количество и рассчитает общую сумму. Также включает встроенный инженерно-бытовой калькулятор с поддержкой OCR.

> **Важно:**
> * Режим **«Почта»** откалиброван для интерфейса почты/хранилища Stalzone.
> * Для работы вкладок **«Торговля»** и распознавания чисел со скриншота требуется **Windows 10/11** со встроенным языковым пакетом распознавания текста (Windows OCR).

---

## Режимы работы (Вкладки)

1. **Почта** — визуальный анализ сетки инвентаря: поиск слотов, сравнение иконок по форме и цвету (`items/`), считывание количества по шаблонам цифр (`digits/`).
2. **Торговля** — текстовый анализ списков формата `Название x 126` через Windows OCR с нечётким поиском и автоматическим исправлением типичных ошибок распознавания.
3. **Калькулятор** — встроенный калькулятор (`+`, `−`, `×`, `÷`, `%`, `±`) с поддержкой приоритета операций, переносом суммы из таблицы и вставкой чисел прямо со скриншотов.

## Структура файлов и папок

Рядом с исполняемым файлом (`MooSC v0.11.8.exe` или `calculator.py`) располагаются рабочие директории и конфигурации:

| Файл / Папка | Назначение |
| :--- | :--- |
| `MooSC v0.11.8.exe` | Исполняемый файл программы. |
| `prices.txt` | База цен в формате `Название=цена`. |
| `items/` | Эталонные изображения слотов предметов (`.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`). |
| `digits/` | Шаблоны цифр (`0.png`–`9.png`) и автоматически созданные примеры (`3_ex1.png` и др.). |
| `Errors/` | *Создаётся автоматически.* Сюда сохраняются уникальные неопознанные слоты. |
| `debug/` | *Создаётся автоматически.* Выгруженные слоты, глифы цифр и варианты обработки OCR. |
| `trade_aliases.txt` | *Создаётся автоматически.* Словарь автозамен для ошибок OCR (`ошибка=правильное название`). |
| `trade_examples.txt` | *Опционально (создаётся вручную).* Дополнительный список эталонных названий для торговли. |

## Быстрый старт и настройка

### 1. Настройка цен
В базовой поставке файл `prices.txt` может быть пустым:
1. Запустите программу и нажмите **«Обновить prices.txt»** — все предметы из папки `items/` добавятся в файл со стартовой ценой `1`.
2. Укажите актуальные цены двойным кликом по ячейке **«Цена»** в таблице или отредактируйте `prices.txt` в любом текстовом редакторе.

### 2. Установка Windows OCR (для «Торговли» и вставки чисел)
Если программа сообщает об ошибке запуска распознавания текста, установите языковой пакет через **PowerShell (от имени администратора)**:

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
```
*(Программа поддерживает языки `ru` и `uk`, по умолчанию используется первый доступный из списка).*

## Подробное руководство по вкладкам

### Вкладка «Почта» (Распознавание иконок)
1. Сделайте скриншот области со слотами предметов (например, `Win + Shift + S`).
2. Нажмите **«Вставить скриншот»** или `Ctrl+V`.
3. Программа выведет таблицу с позицией `(ряд, колонка)`, миниатюрой, названием, количеством, ценой, суммой, визуальной долей от итога и коэффициентом совпадения.

**Цветовая индикация строк:**
* **Зелёный** — самая дорогая позиция в списке.
* **Жёлтый** — предмет опознан, но для него не задана цена в `prices.txt`.
* **Красный** — предмет не опознан (с указанием ближайшего кандидата, если он найден).

**Редактирование и самообучение (двойной клик по ячейке):**
* **Предмет:** Позволяет задать имя неопознанному предмету (иконка автоматически сохранится в `items/`) или переименовать уже известный (файл в `items/` и запись в `prices.txt` обновятся автоматически).
* **Кол-во:** Исправляет неверно считанное число. Если количество найденных на слоте глифов совпадает с длиной введённого числа, программа сохранит новые образцы цифр в `digits/` (например, `5_ex1.png`) и сразу пересчитает остальные слоты.
* **Цена:** Изменяет стоимость предмета и мгновенно сохраняет её в `prices.txt` (оставьте поле пустым, чтобы удалить цену).

> **Примечание:** В названиях запрещены символы `\ / : * ? " < > | =`, а также символы `#` и `?` в начале строки. Для разового подтверждения кандидата без сохранения в `items/` нажмите **«✔ принять»** в колонке «Подтв.».

### Вкладка «Торговля» (Распознавание текста)
Предназначена для скриншотов текстовых списков вида `Мякоть солевика x 126`.
1. Переключитесь на вкладку **«Торговля»** и вставьте скриншот (`Ctrl+V`).
2. Программа прогонит изображение через несколько фильтров (увеличение, удаление виньетки, повышение резкости, бинаризация) и сопоставит строки с базой `prices.txt`, `trade_examples.txt` и `trade_aliases.txt`.
3. Если OCR исказил название, исправьте его двойным кликом по ячейке **«Предмет»** или примите предложенного кандидата — программа запишет правило в `trade_aliases.txt` и в будущем будет исправлять эту ошибку автоматически.

---

### Вкладка «Калькулятор»
Полноценный калькулятор с поддержкой ввода с клавиатуры (`0-9`, `+`, `-`, `*`, `/`, `%`, `Enter`/`=`, `Backspace`, `Esc`/`Delete` для сброса, `Ctrl+C` для копирования).

**Специальные функции:**
* **← ИТОГО из таблицы:** Переносит общую сумму из последнего расчёта в «Почте» или «Торговле».
* **Вставить число (`Ctrl+V`):** Распознаёт число из текста в буфере обмена или прямо со скриншота (например, `8 650 000 рублей` превратится в `8650000`). Вставленное число подставляется как текущий операнд, не стирая уже набранное выражение (например, `100 + [вставка]`).

## Панель управления и подготовка базы

* **↻ Перезагрузить:** Перечитывает папки `items/`, `digits/` и файл `prices.txt`, заново анализируя текущий скриншот.
* **Сохранить слоты/цифры:** Выгружает в папку `debug/` нарезанные слоты (`debug/slots/`) и символы (`debug/glyphs/`), а в режиме торговли — варианты предобработки для OCR. Удобно использовать для наполнения папок `items/` и `digits/` чистыми эталонами.
* **Папка Errors:** Открывает директорию с автоматически сохранёнными неопознанными предметами (дубликаты отсеиваются автоматически).
* **Обновить prices.txt:** Синхронизирует `prices.txt` с содержимым папки `items/`, добавляя новые предметы с ценой `1` и сохраняя существующие цены и комментарии.

## Решение частых проблем

* **«В буфере обмена нет скриншота»** — убедитесь, что скопировано именно изображение, а не файл в проводнике или текст.
* **Все предметы не опознаны** — проверьте, что в папке `items/` есть эталоны и они сняты в том же масштабе интерфейса игры, что и новый скриншот.
* **Количество всегда определяется как `1`** — проверьте индикатор вверху окна: должно быть `цифр: 10/10`. Убедитесь, что в папке `digits/` лежат файлы `0.png`–`9.png`.
* **Неточное распознавание числа со скриншота в калькуляторе** — старайтесь обрезать скриншот максимально плотно вокруг нужного числа, чтобы в кадр не попадал лишний игровой интерфейс.
